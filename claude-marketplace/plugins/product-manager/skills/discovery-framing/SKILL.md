# Discovery Framing

Use before solution design when the user problem is unclear or contested.

## Inputs

- Research material
- Target segment
- Business context

## Workflow

1. Separate observations from interpretations.
2. Cluster recurring needs and constraints.
3. Write problem statements with evidence.
4. Prioritize learning questions that reduce decision risk.

## Output

- Problem inventory
- Evidence map
- Learning agenda

## Boundaries

- Do not invent quotes.
- Do not treat frequency as importance without context.
- Do not jump directly to features.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
