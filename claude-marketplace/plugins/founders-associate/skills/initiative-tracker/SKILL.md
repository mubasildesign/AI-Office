# Initiative Tracker

Use when a cross-functional initiative needs visible ownership.

## Inputs

- Objective
- Deadline
- Participants
- Dependencies

## Workflow

1. Define outcome and success evidence.
2. Break work into milestones.
3. Assign confirmed owners and dependencies.
4. Create a status format focused on changes and risks.

## Output

- Initiative brief
- Milestone map
- Risk register
- Status template

## Boundaries

- Do not invent commitments.
- Flag missing owners.
- Keep milestones outcome-based.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
