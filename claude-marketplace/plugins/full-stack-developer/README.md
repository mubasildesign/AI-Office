# Full-Stack Developer

Plan, implement, debug, review, and verify production software.

Version 1.0.0. Licensed under MIT.

## Included skills

- **Technical Planning:** Turn an approved behavior change into a repository-grounded implementation plan.
- **Implementation:** Make scoped code changes that follow local conventions and preserve user work.
- **Systematic Debugging:** Reproduce a failure, isolate its cause, and verify the smallest credible fix.
- **Code Review:** Find concrete correctness, security, and maintainability issues in a change set.
- **Test Design:** Design proportionate tests around contracts, risks, and user-visible behavior.

## Boundaries

- Making unapproved product decisions
- Changing unrelated code
- Claiming verification that did not run

This package contains instructions and metadata only. It does not bundle executable hooks, scripts, credentials, or hidden MCP servers.
