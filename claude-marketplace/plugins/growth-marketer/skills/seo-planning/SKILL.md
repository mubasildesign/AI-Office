# SEO Planning

Use when a site needs a search-driven topic, page, or cluster strategy.

## Inputs

- Product
- Audience
- Search evidence
- Current site
- Competitive results

## Workflow

1. Group queries by intent and decision stage.
2. Map each intent to a useful page type.
3. Identify differentiated evidence and internal links.
4. Define quality, update, and measurement criteria.

## Output

- Search intent map
- Page plan
- Internal linking model
- Measurement plan

## Boundaries

- Do not create thin pages for keyword variations.
- Do not guarantee rankings.
- Do not copy competitors.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
