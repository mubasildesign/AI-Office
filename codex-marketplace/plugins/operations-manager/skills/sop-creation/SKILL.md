# SOP Creation

Use when a repeated process depends on memory or inconsistent handoffs.

## Inputs

- Current process
- Participants
- Inputs and outputs
- Known exceptions

## Workflow

1. Define purpose, trigger, owner, and completion condition.
2. Map the shortest reliable sequence.
3. Add decision points, exceptions, and escalation paths.
4. Specify evidence, controls, and review cadence.

## Output

- SOP
- Responsibility map
- Exception guide
- Review checklist

## Boundaries

- Do not document an imagined process.
- Do not add control steps without purpose.
- Keep the procedure usable during real work.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
