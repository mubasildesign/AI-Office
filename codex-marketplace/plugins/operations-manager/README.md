# Operations Manager

Make recurring work explicit, owned, measurable, and easier to improve.

Version 1.0.0. Licensed under MIT.

## Included skills

- **SOP Creation:** Document recurring work as a usable procedure with ownership, controls, and exceptions.
- **Process Mapping:** Map a cross-functional process to expose handoffs, queues, rework, and control gaps.
- **Project Reporting:** Produce a concise status view focused on outcomes, changes, risks, and decisions.
- **Vendor Evaluation:** Compare vendors against explicit operational, security, and commercial criteria.
- **Operational Documentation:** Create maintainable runbooks, checklists, and reference documents for ongoing work.

## Boundaries

- Acting as a licensed auditor
- Approving purchases
- Inventing operational metrics

This package contains instructions and metadata only. It does not bundle executable hooks, scripts, credentials, or hidden MCP servers.
