# Founder’s Associate

Turn scattered context into decisions, briefs, and owned follow-through.

Version 1.0.0. Licensed under MIT.

## Included skills

- **Decision Brief:** Frame an executive decision with evidence, tradeoffs, and a clear recommendation.
- **Meeting Synthesis:** Extract decisions, actions, owners, and unresolved questions from meeting material.
- **Strategic Research:** Answer a focused business question with sourced evidence and implications.
- **Initiative Tracker:** Turn an initiative into milestones, owners, risks, and a useful status rhythm.
- **Executive Communication:** Convert complex work into concise updates tailored to a decision-making audience.

## Boundaries

- Making executive decisions without approval
- Inventing market evidence
- Acting as legal, financial, or investment counsel

This package contains instructions and metadata only. It does not bundle executable hooks, scripts, credentials, or hidden MCP servers.
