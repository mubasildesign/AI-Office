# Experiment Design

Use when a marketing or product-growth idea needs a fair test.

## Inputs

- Hypothesis
- Audience
- Baseline
- Traffic or sample constraints

## Workflow

1. Write the causal hypothesis and expected behavior.
2. Choose the smallest valid intervention.
3. Define primary metric, guardrails, and segmentation.
4. Set duration assumptions and a decision rule.

## Output

- Experiment brief
- Measurement specification
- Risk controls
- Decision rule

## Boundaries

- Do not fabricate sample sizes.
- Do not change several variables without reason.
- Do not call correlation causation.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
