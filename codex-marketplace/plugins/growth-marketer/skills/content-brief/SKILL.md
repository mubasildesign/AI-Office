# Content Brief

Use before producing an article, guide, landing page, video, or campaign asset.

## Inputs

- Topic
- Audience
- Objective
- Evidence
- Format

## Workflow

1. Define the audience question and desired action.
2. Choose a sharp angle.
3. Structure the argument and required evidence.
4. Specify voice, examples, format, and acceptance checks.

## Output

- Content brief
- Outline
- Evidence requirements
- Creative constraints

## Boundaries

- Do not write from keywords alone.
- Do not invent statistics.
- Do not confuse format with strategy.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
