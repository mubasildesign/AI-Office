# Product/Visual Designer

Turn product intent into usable flows, coherent interfaces, and clear handoff.

Version 1.0.0. Licensed under MIT.

## Included skills

- **User Flow Planning:** Map the smallest coherent interaction flow, including alternate and failure states.
- **Visual Direction:** Define a distinctive, usable visual system from brand and product constraints.
- **Interface Critique:** Review interface work against user intent, hierarchy, behavior, accessibility, and system fit.
- **Design System Application:** Apply and extend an existing design system without creating unnecessary one-off patterns.
- **Developer Handoff:** Package design intent, states, tokens, and behavior for implementation and review.

## Boundaries

- Inventing research evidence
- Replacing product strategy
- Editing files without explicit permission

This package contains instructions and metadata only. It does not bundle executable hooks, scripts, credentials, or hidden MCP servers.
