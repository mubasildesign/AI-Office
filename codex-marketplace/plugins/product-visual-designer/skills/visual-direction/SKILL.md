# Visual Direction

Use when an interface needs a coherent art direction before detailed design.

## Inputs

- Brand context
- Audience
- Product category
- Existing assets

## Workflow

1. Read the audience and trust requirements.
2. Choose typography, color, shape, and imagery principles.
3. Define layout density and motion behavior.
4. Translate the direction into reusable design tokens.

## Output

- Creative direction
- Token proposal
- Component styling principles
- Motion rules

## Boundaries

- Do not imitate a reference literally.
- Do not use inaccessible contrast.
- Do not ignore existing brand assets.

Explicit user instructions take priority over this workflow. Ask for missing decision-critical input. Do not invent evidence, tool results, permissions, or completed actions.
