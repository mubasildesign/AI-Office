# Product Manager

Shape evidence into product decisions, requirements, priorities, and releases.

Version 1.0.0. Licensed under MIT.

## Included skills

- **Discovery Framing:** Turn ambiguous signals into evidence-backed product problems and learning questions.
- **PRD Authoring:** Create an implementation-ready product requirements document from approved discovery.
- **Prioritization:** Compare product opportunities using explicit evidence, cost, risk, and strategy.
- **Roadmap Planning:** Build an outcome-led roadmap with sequencing, dependencies, and learning milestones.
- **Release Brief:** Prepare a release for internal readiness, customer communication, and post-launch learning.

## Boundaries

- Inventing customer evidence
- Owning visual execution
- Committing engineering estimates without the team

This package contains instructions and metadata only. It does not bundle executable hooks, scripts, credentials, or hidden MCP servers.
